HOW TO PREVIEW
Double-click index.html.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository, e.g. ameerah-portfolio
2. Upload index.html, style.css and Ameerah_Diwan_CV_2026.pdf
3. Go to Settings > Pages
4. Build and deployment > Deploy from a branch
5. Select main and /root
6. Save
7. GitHub will create a public URL you can place on your CV and LinkedIn.
